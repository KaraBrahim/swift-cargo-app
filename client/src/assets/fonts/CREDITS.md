# TwemojiCountryFlags.woff2

Flag glyphs only (~78 KB), from **country-flag-emoji-polyfill** (MIT), built from
**Twemoji** — © Twitter, Inc and other contributors, graphics licensed
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).

Source: https://github.com/talkjs/country-flag-emoji-polyfill

The file is kept in the repository rather than fetched from a CDN: the desks run
offline, and a flag that only appears when the internet does is not a flag.
It is loaded only on browsers that cannot draw 🇩🇿 themselves — Chrome on
Windows, in practice — see `src/main.jsx`.
